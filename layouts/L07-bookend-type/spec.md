# Bookend Type

**Visual test:** Giant type bands pin the top and bottom edges of the format, and the image or information sits in the gap between them.

## Layout
- **Structure:** Three horizontal zones: oversized type band (top), content zone (middle), oversized type band (bottom). Bands often bleed off the sides.
- **Hierarchy:** Type bands dominate; content is framed and secondary.
- **How it extends (page + site):** Down a page: a giant wordmark header and a giant footer wordmark bracket the scrolling content. Across a site: the bands become persistent header/footer.
- **Web first screen:** Viewport-wide wordmark across the top, another across the bottom, image or text in between.

## Tone
Loud, poster-like, brand-forward. Heavy or condensed grotesk, high contrast, often one bright accent. Pairs with: Monumental Type, Expressive Typographic, Web Brutalism.

## Not
Not Monumental Type Fill (one word fills the whole format). Not a normal header (the bands are display scale, not navigation).
