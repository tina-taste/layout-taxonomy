# Lone Object in Void

**Visual test:** One object, under ~30% of the area, sits roughly centred in a flat empty field; type is minimal.

## Layout
- **Structure:** Single centred focal image (cut-out or photographed object) on a solid ground; one short caption or label.
- **Hierarchy:** One focal point, everything else recedes.
- **How it extends (page + site):** Down a page: one object per screen, each section a new object on its own field. Across a site: product/detail pages are single objects in voids.
- **Web first screen:** One product or object centred on a solid background with large negative space and a tiny caption.

## Tone
Reverent, still, product-as-sculpture. Solid neutral or single saturated ground, soft even light, minimal serif or grotesk. Pairs with: Slow Lifestyle, Neo-classical Luxury, Glossy Conceptual, Dutch Reductive.

## Not
Not Whisper Margins (empty centre). Not a product grid (many objects). Not a full-bleed hero (object doesn't fill the frame).
