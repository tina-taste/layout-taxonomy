# Exposed Ruled Grid

**Visual test:** The grid is drawn: hairline rules, cells or crosshairs are visible, and every element snaps into a cell.

## Layout
- **Structure:** A visible modular grid (columns + rows) with hairline borders. Cells hold mixed content: labels, numbers, thumbnails, short text.
- **Hierarchy:** Flat — no single hero. Emphasis comes from which cells are filled vs empty and type size inside cells.
- **How it extends (page + site):** Down a page: the ruled grid continues as a table/calendar; sections are new rows. Across a site: the same rule system frames every page.
- **Web first screen:** Hairline-bordered cells across the whole viewport, like a spreadsheet or calendar, each holding a label, number or thumbnail.

## Tone
Systematic, technical, archival. Neutral ground, black hairlines, one accent colour, monospace or neo-grotesk. Pairs with: Strict Modular Swiss, Systems Modernism, Neo-Swiss Archive, Diagrammatic Interface.

## Not
Not Specimen Matrix (uniform photos, no rules). Not Colour Block Mosaic (filled colour, no rules). Not a bento grid (rounded cards, no visible rules).
