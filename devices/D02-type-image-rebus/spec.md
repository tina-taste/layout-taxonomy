# Type-Image Rebus (graphic device)

**Visual test:** Small images sit inline within lines of large type, read as one sentence.

Not a layout on its own: it is a treatment applied inside a layout (e.g. a hero inside Split Field, a headline inside Bookend Type). Tag it as a modifier alongside a layout style.
